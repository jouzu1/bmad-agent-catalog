## 🔄 Bagian 2: Alur Siklus Proyek (Workflow SDLC)

### Fase 1: Discovery & Analysis
* `/bmad-brainstorming` - Fasilitasi sesi curah pendapat dengan berbagai teknik kreatif.
* `/bmad-forge-idea` - Menguji keras sebuah ide (*pressure-test*) sebelum terlanjur dikerjakan.
* `/bmad-prfaq` - Format Amazon *Working Backwards* (Press Release & FAQ).
* `/bmad-product-brief` - Membuat dokumen ringkasan produk (Product Brief).
* `/bmad-market-research` - Analisis pasar, kompetitor, tren, dan kebutuhan user.
* `/bmad-domain-research` - Analisis mendalam istilah dan model bisnis industri tertentu.
* `/bmad-technical-research` - Uji kelayakan teknis dan eksplorasi opsi arsitektur.

### Fase 2: Planning & Specifications
* `/bmad-prd` - Siklus hidup PRD (bikin baru, update, atau validasi PRD).
* `/bmad-architecture` - Menghasilkan *architecture spine* (invariants & boundaries).
* `/bmad-ux` - Rencana pola interaksi UX dan spesifikasi wireframe.
* `/bmad-create-epics-and-stories` - Memecah PRD dan Arsitektur menjadi daftar Epics dan User Stories.
* `/bmad-check-implementation-readiness` - Audit kelengkapan sebelum mulai koding.
* `/bmad-sprint-planning` - Menyusun sprint status tracking dari daftar epics.

### Fase 3: Execution & Implementation
* `/bmad-create-story` - Membuat file spek *next user story* secara mendalam untuk developer.
* `/bmad-dev-story` - Mengimplementasikan kodingan berdasarkan file story spec.
* `/bmad-quick-dev` - *Fast-track workflow* — dari ide langsung jadi kodingan yang siap dites.
* `/bmad-sprint-status` - Cek progres sprint dan deteksi risiko keterlambatan.
* `/bmad-correct-course` - Manuver darurat saat ada perubahan scope besar di tengah sprint.
* `/bmad-retrospective` - Sesi evaluasi post-epic untuk pembelajaran sprint.

## 🛡️ Bagian 3: Code Review, Audit & Quality Assurance

* `/bmad-code-review` - Review kode paralel 3 lapis (*Blind Hunter*, *Edge Case Hunter*, *Acceptance Auditor*).
* `/bmad-review-edge-case-hunter` - Menelusuri semua percabangan boundary, null, concurrency, dan kasus ekstrem.
* `/bmad-review-adversarial-general` - Review sinis yang mengasumsikan kode akan memicu insiden produksi.
* `/bmad-qa-generate-e2e-tests` - Bikin automated end-to-end test untuk fitur yang ada.
* `/bmad-checkpoint-preview` - Memandu human review sebelum kode di-merge ke branch utama.

## 📦 Cara Instalasi & Setup ke Project

1. Copy folder `skills/` ke dalam `.agent/skills/` atau `.agents/skills/` di project Anda.
2. Copy `config/bmad-party-mode.toml` ke `_bmad/custom/bmad-party-mode.toml`.
3. Jalankan `resolve_party.py --list-groups` untuk memverifikasi seluruh roster.
